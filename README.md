## 🚀 Sobre mí

Soy desarrollador fullstack con experiencia en el desarrollo de aplicaciones web y móviles utilizando tecnologías modernas del ecosistema Java y JavaScript.  
Me enfoco en construir soluciones funcionales, escalables y seguras.

Trabajo con **Angular** e **Ionic** para el desarrollo de interfaces web y aplicaciones híbridas, y con **Spring Boot** en el backend, integrando bases de datos como **MySQL**, así como herramientas como **Spring Security**, **JWT** y **JPA/Hibernate** para la autenticación, seguridad y persistencia de datos.

Además, tengo conocimientos en **redes informáticas** (modelo OSI, direccionamiento IP, puertos, protocolos, etc.), lo cual refuerza mi enfoque en la **seguridad informática** y me permite comprender mejor la comunicación entre sistemas distribuidos y servicios.
